## ★ 必须提供的信息（本流水线仅需 4 个 secrets）

**CI 完全不接触 ACR 凭据（服务器侧已有 docker login），只需部署通道四件套：**

| # | 仓库 secret | 值 | 说明 |
|---|---|---|---|
| 1 | `DEPLOY_HOST` | gb-test 主机地址 | |
| 2 | `DEPLOY_USER` | SSH 用户名 | |
| 3 | `DEPLOY_KNOWN_HOSTS` | `ssh-keyscan -H <host>` 输出 | 钉死指纹防 MITM |
| 4 | `DEPLOY_KEY` | 专用受限钥私钥 | 强制命令锁定 `/opt/apps/core/build.sh`；app41/sanguo/novel-universe 的钥各锁死在各自脚本，不可复用 |

（以上四项均已代配完毕。ACR 三件套不需要——服务器侧已有 docker login。）

## 0. 前置

- gb-test 服务器可 SSH，装有 docker + docker compose 插件、curl。
- 阿里云 ACR 个人版实例（与 app41 / novel-universe / sanguo 同实例），命名空间 `xiaowenz`。
- 仓库公开 → 服务器免凭据拉源码 tarball（codeload）。

## 1. 服务器：部署目录与脚本

```sh
ssh <user>@gb-test
mkdir -p /opt/apps/core
# 本仓库 docker/ 三文件放进去：
#   docker/build-remote.sh    -> /opt/apps/core/build.sh    （受限命令：构建+推送+部署）
#   docker/deploy-remote.sh   -> /opt/apps/core/deploy.sh   （pull 幂等 + up + 冒烟）
#   docker/docker-compose.yml -> /opt/apps/core/docker-compose.yml
chmod +x /opt/apps/core/build.sh /opt/apps/core/deploy.sh

# compose 的 ${ACR_REGISTRY} 由同目录 .env 提供（docker compose 自动读取）：
echo 'ACR_REGISTRY=crpi-xxxx.cn-heyuan.personal.cr.aliyuncs.com' > /opt/apps/core/.env
chmod 600 /opt/apps/core/.env

docker login <ACR_REGISTRY>   # 服务器侧一次（已与其他应用共用登录态）
```

`env`（CORE_* 全部环境变量，含机密）与 `data/`（SQLite）沿用迁移期已有的，
不做任何改动。

## 2. 服务器：受限部署密钥（专用密钥对，绝不复用其他应用的）

```sh
# 本机生成专用密钥对（无口令）
ssh-keygen -t ed25519 -f ~/.ssh/core-deploy -N '' -C 'core-deploy'

# 服务器 authorized_keys 追加（强制命令接管 build.sh + 关闭一切转发/终端）：
command="/opt/apps/core/build.sh",no-port-forwarding,no-X11-forwarding,no-agent-forwarding,no-pty ssh-ed25519 AAAA... core-deploy

# 私钥全文 -> 仓库 secret DEPLOY_KEY
```

## 3. 仓库：GitHub secrets 与 deploy job

- `gh secret set` 写入上表四项。
- `.github/workflows/ci.yml` 的 `deploy` job：push main（go + docker 双 job
  全绿后）或 workflow_dispatch，经受限密钥把 `$GITHUB_SHA` 传给 build.sh；
  `concurrency: deploy-main` 排队不取消。PR 只跑测试不部署。

## 4. 迁移与回滚（从手工 docker run 容器迁来）

- 迁移即首次 `docker compose up -d`：同名容器被 compose 接管重建，bind mount
  `./data:/data` 与 `env` 文件逐项对齐（迁移前已核对 env 键一致），SQLite 不丢。
- 回滚：compose 的 `image` 改回本地旧镜像 `xiaowenz-core:latest`（迁移期手建，
  保留在服务器）再 `docker compose up -d`。
